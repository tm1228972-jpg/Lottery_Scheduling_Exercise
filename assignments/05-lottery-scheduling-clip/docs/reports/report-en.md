# Exercise 5 Report — Lottery Scheduling, EDF, and RM Clip

## Asset specification

`outputs/lottery-scheduling-comparison.mp4` was generated by the repository script: H.264, 1280×720, 10 frames/s, 12 bilingual caption sections, and a verified duration of 132 seconds (2:12). The clip is silent; Persian and English captions are embedded, and separate narration scripts are provided. No voice-over is claimed.

## Content outline

The clip frames the distinction between proportional share and deadline completion. It then explains tickets and `pᵢ=tᵢ/T`, finite-sample variation, EDF's absolute-deadline rule, and RM's period-based fixed priority. It uses the supplied Exercise 3 task set and embeds the actual Gantt output from the repository simulator. The final sections state theorem assumptions and model limitations, cite Waldspurger and Weihl (1994) and Liu and Layland (1973), and show reproduction commands.

## Technical comparison

| Policy | Decision rule | Result under stated model |
|---|---|---|
| Lottery | Random ticket from the ready set | Expected share `tᵢ/T`; no hard deadline or finite waiting bound |
| EDF | Earliest absolute deadline | `U≤1` for ideal implicit-deadline uniprocessor tasks |
| RM | Shorter period receives fixed priority | Liu–Layland bound is sufficient, not necessary |

The clip is not an “all real system aspects” benchmark. It does not simulate overhead, blocking, jitter, multicore scheduling, or production workloads. These limits are stated in the captions and narration script.
